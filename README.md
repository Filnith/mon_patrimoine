# Mon Patrimoine

Appli web installable (PWA) pour suivre ses comptes et placements. Les données restent dans le navigateur du téléphone (localStorage).

- Cryptos : cours via l'API publique de CoinGecko, sans clé.
- Actions et ETF : clé gratuite Alpha Vantage ou EODHD à coller dans les réglages, sinon cours saisis à la main.
- Taux dollar/euro : api.frankfurter.app, ou saisie manuelle.

Les indications de risque et les signaux ne constituent pas un conseil en investissement.
